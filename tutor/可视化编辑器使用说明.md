# 可视化编辑器使用说明

本模板把常用的改造入口放进了本地开发页面左下角的一个工具菜单：**贴纸、运镜、资料**。它们只在 `npm run dev` 期间显示，并把结果保存到仓库文件。

## 开始前

```bash
cd web
npm install
npm run dev
```

打开 `http://localhost:5173/`，点击左下角的工具按钮。菜单会向上展开。

## 资料：替换首屏个人信息

选择“资料”后，可编辑：

- 姓名、职业、所在地、作品集标识和页脚信息。
- 中英文标题与自我介绍。
- 邮箱、个人网站、技能标签等自定义信息；每条都可以新增、修改和删除。

修改会立即反映在首屏。点击“保存资料”后，内容写入 `web/public/profile/profile.json`。

“预设 1”始终代表模板原始资料。点击它可以切回默认内容，同时保留此前的自定义草稿，方便再次编辑。

## 运镜：替换模型与编辑关键帧

### 导入模型

1. 将 `.glb` 文件复制到 `web/public/models/`。
2. 打开“运镜”，选择“模型”。
3. 点击“刷新”，再点击列表中的模型名称。

当前选择保存到 `web/public/models/model-selection.json`。模型缺少相机、焦点空对象或眼睛网格时，模板会回退到静态镜头与模型中心焦点，仍可正常预览。

### 创建自定义镜头

1. 在“运镜”中选择“自定义”。
2. 拖动时间轴到目标时刻，点击“在此加帧”。
3. 编辑镜头偏移、焦点偏移、FOV、虚化强度和清晰范围。
4. 继续添加关键帧，完成后点击“保存配置”。

自定义模式会冻结 GLB 的 `CameraAction`，使关键帧成为镜头的主控制方式。想恢复模型自带动画时，选择“预设 1”并保存。

配置文件为 `web/public/director/camera-overrides.json`。

## 贴纸：摆放并烘焙到模型

1. 准备透明背景 PNG 或 WebP，放到 `web/stickers/`。
2. 打开“贴纸”，刷新列表并选择一张图片。
3. 开启放置模式，在模型上点击或拖动；也可以用右侧控制项精调位置、旋转和缩放。
4. 点击“保存配置”。需要把效果写进模型纹理时，再点击“生成 GLB”。

贴纸配置保存在 `web/stickers/stickers.json`；生成 GLB 前会创建快照，方便在贴纸面板中回滚。烘焙过程依赖模型中的 `man` 节点，详细实现见 [贴纸烘焙说明](../web/stickers/README.md)。

## 保存、构建与发布

编辑器保存的是本地文件。完成编辑后：

```bash
cd web
npm run typecheck
npm run build
```

将 JSON、GLB、贴纸配置与代码一起提交，再部署 `web/dist/`。GitHub Pages 与其他静态托管只能展示已保存的结果，不能让线上访客直接保存资料或编辑模型。
